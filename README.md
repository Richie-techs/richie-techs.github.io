# ShipTrack — Shipment Tracking Website

A responsive front-end demo for tracking shipments using HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in your browser.

## Demo tracking numbers
- `ST-2048-7319` — In transit
- `ST-8851-2046` — Delivered

## Publish with GitHub Pages
1. Create a GitHub repository named `shiptrack-website`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub to publish the site; the Pages URL will appear in Settings → Pages.

## Important limitation
This is a front-end demonstration. The two tracking numbers and their statuses are hard-coded sample data. Real shipment tracking requires a backend/database and a courier API or an admin workflow for updating shipment events. Do not put API secrets in browser-side JavaScript.
